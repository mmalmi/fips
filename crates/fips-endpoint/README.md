# fips-endpoint — frozen

This package is frozen. This final release changes only this notice; its library code is unchanged. No further releases are planned under the `fips-endpoint` name.

For new development with Nostr VPN's independently evolved implementation, use [`nvpn-fips-endpoint`](https://crates.io/crates/nvpn-fips-endpoint). Source: [`mmalmi/fips`](https://github.com/mmalmi/fips).

For the original FIPS project, see [`jmcorgan/fips`](https://github.com/jmcorgan/fips).
